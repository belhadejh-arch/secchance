# منصة الفرصة الثانية — Second Chance Platform (SCP)

منصة رقمية وطنية متكاملة للدعم النفسي، الاستشارات القانونية، ومكافحة الإدمان وفق التشريع الجزائري (القانون 04-18، وتعديلاته بالقانون 23-05 والمرسوم 25-03، والمرسوم التنفيذي 07-229).

## البنية التقنية (Tech Stack)
- **Frontend Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + خط Cairo العربي المعتمد (RTL First)
- **Icons**: Lucide React
- **AI Triage**: Google GenAI integration + Local Algerian clinical triage protocol
- **Deployment**: Vercel & Node.js

## أوامر التشغيل والبناء (Scripts)
- `npm run dev` : تشغيل خادم التطوير المحلي على المنفذ 3000
- `npm run build` : بناء نسخة الإنتاج عبر Vite
- `npm run build:frontend` : أمر البناء المتوافق مع إعدادات Vercel المخصصة
- `npm run preview` : معاينة البناء النهائي

## المميزات الأساسية
1. **لوحات تحكم متخصصة (RBAC)**:
   - عائلة / مواطن (طلب استشارات، متابعة الحالات، الدفع الإلكتروني)
   - أخصائي نفسي عيادي (استقبال الطلبات، كتابة تقارير المتابعة)
   - مستشار قانوني ومحامٍ (استشارات المادة 6 من القانون 04-18)
   - مراكز علاج الإدمان والمؤسسات الاستشفائية والعيادات المتخصصة والجمعيات
   - الإدارة المركزية (متابعة الطلبات، الإيرادات وسجل المعاملات)
2. **المساعد الذكي والتوجيه العيادي (AI Triage)**.
3. **الدفع الإلكتروني الجزائري**: محاكاة الدفع عبر البطاقة الذهبية لبريد الجزائر وبطاقات CIB البنكية.
4. **المواعيد وغرف المحادثة المباشرة**.
5. **دليل المراكز والجمعيات عبر ولايات الجزائر**.
6. **دليل أرقام الطوارئ والنجدة الوطنية (1032, 1055, 1548, 14)**.
